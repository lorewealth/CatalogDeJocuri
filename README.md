# Tema Proiectului: Catalog Digital de Jocuri

## Descriere

Aplicația funcționează ca un manager de colecții de jocuri video. 

### Scopul Principal
Monitorizarea titlurilor pe diferite platforme (Steam, Epic Games, GOG) și analiza evoluției prețurilor pentru optimizarea achizițiilor.

---

## Funcționalități

### Gestionare Catalog
- Adăugarea jocului în catalog
- Modificarea jocului adăugat (system requirements, rating, gen, etc.)
- Ștergerea jocului

### Gestionare Prețuri
- Fiecare joc va avea un grafic de prețuri
- Introducere manuală a prețurilor
- Încărcarea fișierului cu prețuri
- Integrare API (probabil)

### Disponibilitate Platforme
- Afișarea disponibilității pe diferite platforme:
  - Steam
  - Epic Games
  - GOG
  - și altele
